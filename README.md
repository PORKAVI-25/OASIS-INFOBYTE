# Python Programming Practice Projects

This repository contains five beginner-friendly Python console programs:

1. Number Guessing Game
2. Simple Calculator
3. Password Generator
4. To-Do List Manager
5. BMI Calculator

## Requirements
- Python 3.9 or later
- No third-party packages required

## How to run
Open a terminal in this folder and run any file, for example:

```bash
python 01_number_guessing_game.py
```

Replace the filename with the program you want to run.

## Concepts demonstrated
- Variables, input and output
- Conditional statements and loops
- Functions and exception handling
- Lists and string operations
- Random selection and arithmetic calculations
